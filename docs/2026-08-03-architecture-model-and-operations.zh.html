Semantics

状态与概率语义

04

活动状态

collector failures >= 2 -> data_delayed
last activity <= 30m   -> active
30m < age <= 3h        -> cooling
age > 3h / none        -> quiet

确认状态

forecasting
  -> candidate_confirmation
  -> confirmed_reset
  -> retracted

只有权威用户、第一方表述、已发生语义和确定性模式同时成立，才进入 confirmed_reset。

概率递推

先计算 168 小时总事件概率，再按桶权重分配边际概率，最后由 p(bucket)/(1-cumulative_before) 反推 hazard。属性测试覆盖连续性、上限和单调性。

数据陈旧

freshness 来自 Collector 最近成功时间，活动状态来自帖子创建时间。stale 时复用最后预测，不使用惩罚项修改事件概率，只降低 freshness/confidence。

heuristic-v1 模型卡与回测

06

适用范围

  • 展示未来 168 小时相对风险窗口。
  • 输入仅为已持久化的公开活动与结构化信号。
